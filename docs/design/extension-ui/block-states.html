Block states (sample sheet)

A. State key: tag, meaning, buttons

StateMeaningButtons
+New Not in review yet. A scan found it as a lesson word. Start learning; I know this
~Learning In review. Answers still being checked. Mark known; Back to new
✓Known Not in review. Set by you, or by the course when its topic moves to known. Learn again; Back to new
–Not tagged Scan result, not a knowledge state. The block was not scanned as a lesson word. None

B. Transitions

  1. New to Learning: Start learning, or answer 1, 2 or 3 in review.
  2. New to Known: I know this (no review step).
  3. Learning to Known: Mark known.
  4. Known to Learning: Learn again.
  5. Learning or Known back to New: Back to new.
  6. Undo: every change shows an Undo bar. Undo returns the block to its previous state and stays until the next change.
  7. Not tagged has no transitions: a new scan can replace it with a state.
