Side panel: navigation map

One map of every panel screen and the settings page. Each screen links to its mockup. The panel has one header, one bottom tab bar, and Back on every screen below the first.

A. Where the controls sit (home screen)

Auto-scan this site

Results of the last scan appear here, grouped by topic.

  1. 1 Back: top left of the header. Shown on every screen except Page. Returns to the screen before.
  2. 2 Course picker: top middle of the header. Shows the current course. Opens the Courses screen.
  3. 3 Settings entry: gear at top right of the header. Opens the Settings page.
  4. 4 Scan button: first control under the header on the Page screen.
  5. 5 Auto-scan toggle: under the scan button, for the current site only. Off by default.
  6. 6 Review entry: right tab in the bottom tab bar. Opens the Review screen.

B. Screens and where they link

  • Home (Page tab)

    Scan button, auto-scan toggle, course line, last results.

    • Scan button to Scanning
    • Course picker to Courses
    • Settings gear to Settings
    • Review tab to Review

    Mockup: panel-states.html, Idle

  • Scanning

    Progress while the page is read. Cancel returns to Home.

    Mockup: panel-states.html, Scanning

  • Results (grouped by topic)

    Rows grouped by topic. Selecting a row scrolls the page to its block.

    • Row to the block on the page (no screen change)
    • Back to Home

    Mockup: panel-states.html, Results

  • Detail (one block)

    One block with its state buttons and undo. Opened from a row.

    • Back to Results

    Mockup: panel-states.html, I know this

  • Review

    Words to repeat. Opened from the Review tab.

    Mockup: panel-states.html, Review

  • Courses (list)

    Opened from the course picker. Selecting a course opens the course screen.

    • Course to Course screen
    • New course to Create
    • Back to Home

    Mockup: panel-states.html, Courses list

  • Course screen

    One course: name, topics, delete.

    • Delete to Delete confirm, then Courses
    • Back to Courses

    Mockup: panel-states.html, Course open and Delete

  • Settings

    Connection, auto-scan site list, appearance, about. Opened from the gear.

    • Back to Home

    Mockup: settings.html (light and dark)

C. State screens (replace the normal screen while they apply)

  • First run and sign-in: First run, Sign-in. Shown until a server is connected and signed in.
  • Offline: Offline. Shown over Home. Changes wait in the queue.
  • Sign-in expired: Sign-in expired. Shown over any screen; the person signs in again and returns.
  • Empty page and error: Empty page, Error. Shown on Home.

D. The page

The page is not a panel screen. Selecting a panel row scrolls the page to its block; hover or focus on a page block highlights its row. See lesson-page.html for highlights and the detail card.
