What is TCP

TCP is a transport protocol that sits above IP. It numbers every byte so lost segments can be found and resent. The receiver sends acknowledgements back to the sender.

A connection starts with a three-way handshake. Both sides agree on starting numbers before any data moves.

The window field tells the sender how much data the receiver can take. A small window slows the sender, so a slow reader is not flooded.
